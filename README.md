# IYF Season 12 – Week 5: DOM Manipulation

## About This Project

This repository contains my Week 5 assignment for the IYF Weekend Academy Season 12 coding course.

During this week, I learned how JavaScript interacts with HTML elements to make webpages more interactive. I practised selecting elements, changing content, creating new elements, removing elements and responding to different user actions.

I have also included a simple To-Do List application and five daily challenges to put what I learned into practice.

## What I Learned

Some of the main things I practised include:

- Selecting HTML elements using `getElementById()` and `querySelector()`.
- Moving between elements in the DOM.
- Changing text, HTML content, attributes and styles.
- Creating, adding, cloning and removing elements.
- Handling events such as clicks and keyboard actions.
- Using event bubbling and event delegation.
- Validating form inputs.
- Using JavaScript to update a webpage without reloading it.

## Main Project: To-Do List

I created a To-Do List application to practise using the DOM in a practical way.

The application allows users to:

- Add new tasks.
- Mark tasks as completed.
- Delete individual tasks.
- View all, active or completed tasks.
- See how many tasks are still remaining.
- Clear all completed tasks.
- Edit a task by double-clicking it.

The application also checks that users do not submit empty tasks.

## Daily Challenges

I completed five small challenges to practise different DOM manipulation techniques.

### Day 1: Color Changer
A button changes the colours of all the headings on the page using randomly generated HEX colours.

### Day 2: Element Creator
A button creates new numbered paragraphs. Each paragraph has its own delete button.

### Day 3: Image Remover
This page allows users to hide, show or remove all images with a button click.

### Day 4: Content Copier
Content can be copied from one section of the page to another. I also added a drag-and-drop feature.

### Day 5: Dark Mode
Users can switch between light mode and dark mode. The selected theme is saved in the browser using localStorage.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder on your computer.
3. Open `index.html` in your web browser to try the To-Do List.
4. Open `dom-practice.html` to explore the DOM practice exercises.
5. Open the individual HTML files inside the `daily-challenges` folder to try each challenge.

No additional software installation is required to run these pages in a modern web browser.

## Technologies Used

- HTML5 – for the structure of the webpages.
- CSS3 – for styling and layout.
- JavaScript – for DOM manipulation and interactivity.
- Browser localStorage – for saving the dark-mode preference.
